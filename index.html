MoodHealth คืออุปกรณ์ IOT ที่ใช้ในการเช็คสุขภาพของดินสำหรับปลูกพืชคร่าวๆ โดยสามารถเช็ค อุณหภูมิ, ความชื้น ของดินได้ผ่านจอ LCD หรือว่าผ่าน Web app และ สามารถเตือนรดน้ำต้นไม้ได้หากว่าความชื้นน้อยเกินไป

Modules we use

Moisture Sensor

Temperature Sensor ( DS18B20 )

LCD Module

Web Application ( MoodHealth Monitor )

โดยตัว Web App จะสามารถแสดงได้ทั้งค่าความชื้น, และ อุณหภูมิของดิน
พร้อมทั้งแสดงสถานะว่าอุณหภูมิ, และความชื้นอยู่ในระดับปกติหรือไม่

ระบบเตือนลดน้ำต้นไม้

ระบบจะเตือนลดน้ำต้นไม้ หากความชื้นของดินน้อยเกินไปพร้อมแสดงชื่อ และ สถานที่ของต้นไม้ที่ได้ตั้งเอาไว้
และถ้ากดปุ่ม "รดน้ำแล้ว" แล้วค่าความชื้นปกติปุ่มก็จะหายไป

Abstract ( บทคัดย่อ )

โครงงานนี้มีวัตถุประสงค์เพื่อพัฒนาระบบตรวจวัดและแจ้งเตือนสภาพแวดล้อมที่เกี่ยวข้องกับการปลูกพืชผักสวนครัวและไม้ดอกขนาดเล็ก เพื่ออำนวยความสะดวกให้แก่ผู้ที่สนใจเริ่มต้นปลูกพืชและผู้ที่ต้องการดูแลพืชให้เหมาะสมกับความต้องการพื้นฐานของพืชแต่ละชนิด โดยใช้บอร์ดอาร์ดูโน่ร่วมกับ เซ็นเซอร์วัดความชื้น, เซนเซอร์วัดอุณหภูมิ, และ จอ LCD ในการพัฒนาและตรวจวัดข้อมูลที่เกี่ยวข้อง ได้แก่ ... จากนั้นนำข้อมูลที่ได้มาแสดงผลบนหน้าจอlcdและบนเว็บไซต์
